# data/audio/vhf_synth — synthetic VHF voice corpus (not in git except manifests)

- `local/` — espeak-ng voices (pl, pl+f3, en-gb, en-us+m3) rendered from VOICE items and
  passed through the channel augmentation presets (`modal_jobs/augment.py`): clean /
  typical / harsh. Robotic, but the channel model is the real one. Generated by
  `tools/synth_vhf_local.py`; `transcripts.jsonl` is committed, wavs are not.
- `<modal run id>/` — Piper voices from the W2 Modal job, mirrored with `modal volume get`.

All audio here is synthetic. No third-party voice traffic, ever (PRD §12.4, CLAUDE.md §5).
